# Cilium 호환성 가이드

## Kubernetes 버전 호환성

Cilium 1.17은 Kubernetes 1.30 이상 버전과 완벽하게 호환됩니다. 아래 표는 Cilium 버전별 Kubernetes 호환성을 보여줍니다.

| Cilium 버전 | 지원되는 Kubernetes 버전 | 비고 |
|------------|------------------------|------|
| 1.17.x     | 1.30, 1.31, 1.32, 1.33 | 현재 최신 버전 (2025년 7월 기준) |
| 1.16.x     | 1.29, 1.30, 1.31, 1.32 | |
| 1.15.x     | 1.28, 1.29, 1.30, 1.31 | |
| 1.14.x     | 1.27, 1.28, 1.29, 1.30 | |
| 1.13.x     | 1.26, 1.27, 1.28, 1.29 | |

## EKS AutoMode 호환성

EKS AutoMode에서는 API 버전 호환성에 특별한 주의가 필요합니다. 자세한 내용은 [AWS 공식 문서](https://docs.aws.amazon.com/eks/latest/userguide/migrate-auto.html)를 참조하세요.

## 운영체제 호환성

Cilium은 다음 운영체제 및 커널 버전과 호환됩니다:

| 운영체제 | 최소 커널 버전 | 권장 커널 버전 |
|---------|--------------|--------------|
| Ubuntu | 4.19 | 5.15 이상 |
| Debian | 4.19 | 5.15 이상 |
| RHEL/CentOS | 4.19 | 5.10 이상 |
| Amazon Linux 2 | 4.19 | 5.10 이상 |
| Bottlerocket | 5.10 | 5.15 이상 |
| Flatcar Container Linux | 5.10 | 5.15 이상 |

## 알려진 제한사항

1. **커널 버전 요구사항**: eBPF 기능을 완전히 활용하기 위해서는 Linux 커널 4.19 이상이 필요합니다. 일부 고급 기능은 더 최신 커널 버전이 필요할 수 있습니다.

2. **kube-proxy 대체 모드**: kube-proxy를 대체하는 모드에서는 일부 특수한 서비스 유형에 제한이 있을 수 있습니다.

3. **IPv6 이중 스택**: 일부 환경에서는 IPv6 이중 스택 구성에 추가 설정이 필요할 수 있습니다.

4. **Windows 노드**: Cilium은 현재 Windows 노드에 대한 제한적인 지원을 제공합니다.

## 업그레이드 고려사항

Cilium을 업그레이드할 때 다음 사항을 고려하세요:

1. **버전 간 업그레이드**: 항상 릴리스 노트를 확인하고 마이너 버전 단위로 순차적 업그레이드를 권장합니다.

2. **다운타임 최소화**: 업그레이드 중 다운타임을 최소화하기 위한 롤링 업데이트 전략을 사용하세요.

3. **백업**: 업그레이드 전에 Cilium 구성 및 네트워크 정책을 백업하세요.

4. **호환성 확인**: 업그레이드하려는 Cilium 버전이 현재 Kubernetes 버전과 호환되는지 확인하세요.

5. **테스트 환경**: 가능하면 프로덕션 환경에 적용하기 전에 테스트 환경에서 업그레이드를 테스트하세요.
