# 网络基础第 5 部分测验：网络设备、LAN 和 WAN

> **最后更新**：2026年11月19日

测试你对设备转发决策、VLAN 和冗余、LAN 拓扑、NAT、WAN 类型及其云端对应方案的理解。

## 选择题

1. 以下哪项正确描述了 L2 交换机在 VLAN 内以及路由器在子网之间所做的决策？
   - A) 两者都会查找目标 IP 的最长前缀路由
   - B) 交换机会在 MAC 表中查找目标 MAC 以选择端口；路由器会在 FIB 中查找目标 IP，将 TTL 减 1，并写入新的 L2 标头
   - C) 交换机会递减 TTL，路由器会学习源 MAC
   - D) 路由器总是会用自己的地址替换 IP 地址

<details>
<summary>显示答案</summary>

**答案：B) 交换机会在 MAC 表中查找目标 MAC 以选择端口；路由器会在 FIB 中查找目标 IP，将 TTL 减 1，并写入新的 L2 标头**

**解释：**
L2 交换机会学习源 MAC，根据目标 MAC 和 VLAN 选择端口，而且不会更改帧。路由器会按照最长前缀路由将数据包转发到下一跳，递减 TTL，并写入新的源和目标 MAC。没有 NAT 时，IP 地址保持不变，因此 D 错误。

</details>

2. 两台交换机通过 802.1Q 中继链路相连，两台交换机都各有 VLAN 10 和 VLAN 20 的端口，且有一台路由器负责在两个 VLAN 之间路由。共有多少个广播域？
   - A) 1
   - B) 2
   - C) 4
   - D) 每个交换机端口对应一个

<details>
<summary>显示答案</summary>

**答案：B) 2**

**解释：**
一个 VLAN 就是一个广播域；即便一个 VLAN 通过中继链路跨越多台交换机，它仍然是一个广播域。路由器不会将作为 L2 广播接收的数据包转发到其他接口（RFC 1812 §5.3.4），因此共有两个广播域：VLAN 10 和 VLAN 20。每个交换机端口对应一个描述的是冲突域。

</details>

3. 关于 802.1Q 中继链路上的 native VLAN，以下哪项说法正确？
   - A) native VLAN 帧始终带有 VID 4095 标签
   - B) native VLAN 在链路两端可以不同，不会造成任何问题
   - C) 它是通过中继链路时不带标签的 VLAN；在 Cisco Catalyst 上默认是 VLAN 1，且两端必须一致
   - D) native VLAN 仅适用于接入端口

<details>
<summary>显示答案</summary>

**答案：C) 它是通过中继链路时不带标签的 VLAN；在 Cisco Catalyst 上默认是 VLAN 1，且两端必须一致**

**解释：**
设备会将中继链路上收到的无标签帧归入 native VLAN，并以无标签形式发送 native VLAN 帧。如果链路两端的设置不同，一个 VLAN 的帧就会进入另一个 VLAN，从而破坏隔离，还可能导致生成树环路。VID 0 和 4095 是保留值，不用于 VLAN。

</details>

4. 为什么需要 STP？根网桥如何选举？
   - A) 以太网标头没有 TTL，因此 L2 环路中的帧不会消失；STP 会阻塞部分端口，桥接 ID（优先级 + MAC）最低的交换机成为根网桥
   - B) 为了提高 IP TTL；端口最多的交换机成为根网桥
   - C) 为了合并链路带宽；MAC 最高的交换机成为根网桥
   - D) 为了在 VLAN 之间路由；优先级值最高的交换机成为根网桥

<details>
<summary>显示答案</summary>

**答案：A) 以太网标头没有 TTL，因此 L2 环路中的帧不会消失；STP 会阻塞部分端口，桥接 ID（优先级 + MAC）最低的交换机成为根网桥**

**解释：**
出现环路时，广播会持续循环并不断增多，MAC 表也会反复变化。STP 会阻塞部分冗余链路，形成树形拓扑。默认优先级为 32768，因此在没有配置时，MAC 最低的交换机会成为根网桥；实际部署中，会降低核心或汇聚交换机的优先级来固定根网桥。合并带宽是 LACP 的工作。

</details>

5. 在一个使用 LACP 将四条 10 Gbps 链路捆绑起来的 LAG 中，单个 TCP 连接的最大吞吐量是多少？
   - A) 40 Gbps：LAG 会将数据包均匀分散到所有链路
   - B) 最高 10 Gbps：哈希会让同一流始终使用同一条成员链路
   - C) 20 Gbps：发送和接收使用不同链路
   - D) 无论 LAG 如何设置都是 10 Gbps，因为 STP 会阻塞三条链路

<details>
<summary>显示答案</summary>

**答案：B) 最高 10 Gbps：哈希会让同一流始终使用同一条成员链路**

**解释：**
链路聚合会对地址和端口等值进行哈希，将帧分配到某一条成员链路，因此一个流会始终使用同一条链路。只有存在多个流时，才能利用 40 Gbps 的聚合带宽。STP 会将 LAG 视为一条链路，不会阻塞其中的成员链路。

</details>

6. 在 VRRPv3 中，备用路由器的优先级为 100，默认通告间隔为 1 秒。主用路由器停止运行后，备用路由器大约会在多久后接管？
   - A) 约 1 秒
   - B) 约 3.61 秒
   - C) 约 10 秒
   - D) 约 30 秒

<details>
<summary>显示答案</summary>

**答案：B) 约 3.61 秒**

**解释：**
`Active_Down_Interval = 3 × 通告间隔 + Skew_Time`，其中 `Skew_Time = ((256 − 优先级) × 通告间隔) / 256`。 (256 − 100) / 256 ≈ 0.61 秒，因此 3 + 0.61 ≈ 3.61 秒。10 秒是 HSRP 的默认保持时间，30 秒是 802.1D STP 的侦听加学习时间。

</details>

7. 数千个 Pod 通过一个具有单个公有 IPv4 地址的 AWS NAT 网关，调用同一个外部 API（一个 IP:443），随后新连接开始失败。最可能的原因是什么？应如何应对？
   - A) 扩大 NAT 网关的安全组范围
   - B) 每个公有 IP 针对每个唯一目标最多支持 55,000 个并发连接，这个上限可能已达到；检查 `ErrorPortAllocation`，并考虑复用连接、使用辅助 IP 以及将负载分散到多个 NAT 网关
   - C) NAT 网关没有连接数限制，因此一定是外部 API 出现故障
   - D) 在 NACL 中拒绝 443 端口

<details>
<summary>显示答案</summary>

**答案：B) 每个公有 IP 针对每个唯一目标最多支持 55,000 个并发连接，这个上限可能已达到；检查 `ErrorPortAllocation`，并考虑复用连接、使用辅助 IP 以及将负载分散到多个 NAT 网关**

**解释：**
唯一目标是由目标 IP、端口和协议组成的组合，因此流量集中到一个 API 时会最先触及上限。最多可以关联 8 个 IPv4 地址；当无法分配源端口时，`ErrorPortAllocation` 会升至零以上。NAT 网关不能关联安全组，因此 A 错误。

</details>

8. 运营商 CGNAT 与客户驻地设备（CPE）之间的网段使用哪个地址范围？它是什么类型的地址空间？
   - A) `172.16.0.0/12`：RFC 1918 私有地址空间
   - B) `169.254.0.0/16`：链路本地地址空间
   - C) `100.64.0.0/10`：RFC 6598 共享地址空间，与 RFC 1918 地址空间分开
   - D) `203.0.113.0/24`：专门为 CGNAT 保留的公有地址范围

<details>
<summary>显示答案</summary>

**答案：C) `100.64.0.0/10`：RFC 6598 共享地址空间，与 RFC 1918 地址空间分开**

**解释：**
RFC 6598 为 CGN 部署分配了 `100.64.0.0/10`，避免与用户在内部使用的 RFC 1918 地址范围冲突。此地址范围的数据包和路由不得跨越运营商边界。`203.0.113.0/24` 是 RFC 5737 文档示例地址范围。

</details>

9. 一个实例调用外部 HTTPS API。其实例的安全组允许出站 443；子网的自定义 NACL 只允许出站 443，并默认拒绝所有入站流量。为什么响应无法到达？
   - A) 安全组是无状态的，因此必须单独允许入站 443
   - B) NACL 是无状态的，因此必须允许响应返回时使用的临时端口入站（例如 Linux 的 32768–61000）
   - C) NACL 会评估每条规则，然后只应用允许规则
   - D) 安全组中的拒绝规则优先级更高

<details>
<summary>显示答案</summary>

**答案：B) NACL 是无状态的，因此必须允许响应返回时使用的临时端口入站（例如 Linux 的 32768–61000）**

**解释：**
安全组是有状态的，会自动允许返回流量，并且只包含允许规则。NACL 是无状态的子网级过滤器，会按规则编号升序评估允许和拒绝规则，应用第一个匹配项，因此必须明确允许返回流量。

</details>

10. 在两层 spine-leaf 结构的网络中，每个 leaf 都连接到每个 spine，leaf 之间不互连。两台位于不同 leaf 上的服务器之间的流量会经过哪条交换机路径？
    - A) leaf → leaf
    - B) leaf → spine → leaf（三台交换机，两条交换机间链路）
    - C) leaf → spine → spine → leaf
    - D) 取决于服务器的位置，无法预测

<details>
<summary>显示答案</summary>

**答案：B) leaf → spine → leaf（三台交换机，两条交换机间链路）**

**解释：**
由于 leaf 之间不互连，spine 之间也不互连，发往另一台 leaf 的流量总是恰好经过一台 spine。任意一对服务器之间的距离都相同，因此延迟可预测；ECMP 会同时利用所有 spine 路径。

</details>

11. 两个客户都使用私有地址范围 `10.0.0.0/16`。为什么它们的路由在运营商的 MPLS L3VPN 中不会混在一起？
    - A) 运营商使用 CGNAT 转换客户地址
    - B) PE 路由器将客户接入线路绑定到不同的 VRF，并为客户路由添加路由区分符
    - C) SD-WAN 控制器会阻止重复地址
    - D) 租用线路在物理上隔离客户

<details>
<summary>显示答案</summary>

**答案：B) PE 路由器将客户接入线路绑定到不同的 VRF，并为客户路由添加路由区分符**

**解释：**
在 RFC 4364 BGP/MPLS IP VPN 中，PE 路由器会将客户接入线路绑定到称为 VRF 的独立路由表，并在 BGP 携带的客户路由前添加路由区分符，形成不同的 VPN-IPv4 地址，因此不同客户使用重叠的私有地址时不会混在一起。SD-WAN 是构建在电路之上的覆盖网络服务模式；租用线路是点对点电路，与 MPLS L3VPN 是不同的服务。

</details>
