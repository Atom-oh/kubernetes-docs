# Kubernetes 和 EKS 培训内容测验

此目录包含 Kubernetes 和 Amazon EKS 培训内容的测验。每个测验都帮助测试你对主题的理解，并强化关键概念。

## 测验结构

每个测验的结构如下：
- 选择题
- 简答题
- 动手实践题（如适用）
- 进阶题（如适用）

所有测验问题都以可折叠格式包含答案，因此你可以先尝试回答问题，然后再查看答案。
