# SageMaker Qwen 平台架构测验

## 选择题

1. 在此设计中，模型输出与 Python 处理如何配合？

   - A) 模型一定会移除所有 PII
   - B) 模型输出候选 TSV，代码对其进行验证/替换；漏检情况另行评估
   - C) 往返还原可以证明匿名化成功
   - D) 模型会删除项目

<details>
<summary>显示答案</summary>

**答案：B**

确定性替换不会自动找回模型漏检的实体。

</details>

2. 应如何理解图表与验证记录？

   - A) 两条 GPU 路径都已通过验证
   - B) 这是目标设计；应区分本地测试与历史 AWS 观察结果
   - C) 它显示了实时的遗留项目数量
   - D) 它报告了训练后的 F1 和成本

<details>
<summary>显示答案</summary>

**答案：B**

2026-09-01 的记录显示流程在训练前停止。本地测试无法证明 AWS 当前状态或 GPU 执行结果。

</details>

3. 仅凭相同的模型 ID 和随机种子，能否在不同环境中完全复现结果？

   - A) 一定可以
   - B) 不可以；还要验证修订版本、数据哈希、镜像/依赖、CUDA/硬件和执行条件
   - C) 只有 EKS 需要设置随机种子
   - D) 对 QLoRA 而言，分词器并不重要

<details>
<summary>显示答案</summary>

**答案：B**

直接依赖包的固定版本并不等于锁定全部传递依赖；GPU 确定性还有其他要求。

</details>

4. 哪些内容不应写入普通 MLflow 日志/公开报告？

   - A) 数据集哈希
   - B) 经审查的 LoRA 设置
   - C) 原始源文本/补全文本、令牌映射和预签名 URL
   - D) 非敏感的聚合结果

<details>
<summary>显示答案</summary>

**答案：C**

应区分有必要记录在私有清单中的 ID/ARN 与公开披露内容，并验证自动日志记录/跟踪配置。

</details>

5. 关于治理和模型规模，哪项说法正确？

   - A) QLoRA 总是需要 Unified Studio 项目
   - B) 治理流程是本实验选择的程序；3.3B 激活参数不代表模型的总内存需求
   - C) 所有者分配可以原子回滚任何部分失败
   - D) 三小时的作业时限会限制全部实验成本

<details>
<summary>显示答案</summary>

**答案：B**

模型卡列出总计 30.5B/激活参数 3.3B。请分别验证准备状态/所有权以及实际 GPU 内存/成本。

</details>
