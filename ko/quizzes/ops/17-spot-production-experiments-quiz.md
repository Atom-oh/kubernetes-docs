# EKS Spot 운영 적용 실험 퀴즈

> **관련 문서**: [EKS Spot 운영 적용 실험과 결과 판정](../../ops/17-spot-production-experiments.md)

## 1. PDB를 설정한 Spot 노드에서 drain 시험을 통과했습니다. 올바른 해석은?

- A) 실제 Spot 회수에서도 항상 같은 가용성을 보장한다
- B) 자발적 eviction 경로를 검증했으며 실제 회수 시험은 별도로 필요하다
- C) EC2는 PDB가 허용할 때까지 인스턴스 종료를 기다린다
- D) 애플리케이션은 반드시 2분의 종료 시간을 받는다

<details>
<summary>정답 보기</summary>

**정답: B) 자발적 eviction 경로를 검증했으며 실제 회수 시험은 별도로 필요하다**

**설명:** PDB는 EC2의 인스턴스 상실을 막지 못합니다. 실제 중단 통지 전달, eviction 지연, 강제 종료와 서비스 영향은 FIS 회수 및 통지 없는 상실 시험에서 확인합니다.

</details>

## 2. Spot-only selector를 가진 Pod가 Pending입니다. On-Demand 노드를 추가하면?

- A) selector와 관계없이 즉시 이동한다
- B) PDB가 selector를 On-Demand로 바꾼다
- C) selector를 만족하지 못하므로 스케줄되지 않는다
- D) NodePool weight가 selector보다 우선한다

<details>
<summary>정답 보기</summary>

**정답: C) selector를 만족하지 못하므로 스케줄되지 않는다**

**설명:** 폴백에는 공급 용량과 Pod의 배치 호환성이 모두 필요합니다. NodePool의 capacity type만 넓혀도 Spot-only Pod 제약은 그대로 남습니다.

</details>

## 3. NodePool을 On-Demand 전용으로 바꿔 서비스가 정상 기동했습니다. 검증된 내용은?

- A) EC2의 Spot 용량 부족 응답에 대한 자동 폴백
- B) 구성 변경을 통한 On-Demand 전환·스케줄링·기동 경로
- C) 모든 AZ에서 Spot 공급 보장
- D) 기존 Spot Pod의 즉시 자동 이동

<details>
<summary>정답 보기</summary>

**정답: B) 구성 변경을 통한 On-Demand 전환·스케줄링·기동 경로**

**설명:** 전환 훈련은 공급 부족 응답을 주입하지 않았습니다. 실제 provisioning 경로의 오류 처리·폴백은 별도로 검증하고, 재현하지 못했다면 미검증으로 남깁니다.

</details>

## 4. FIS 실험이 `completed`이고 대체 노드가 Ready입니다. 서비스 실험의 합격 조건은?

- A) FIS 상태만으로 통과
- B) Node Ready만으로 통과
- C) client 오류·지연·처리량·정합성 증거까지 기준을 충족
- D) LB 5xx가 없으면 timeout은 무시

<details>
<summary>정답 보기</summary>

**정답: C) client 오류·지연·처리량·정합성 증거까지 기준을 충족**

**설명:** FIS 완료는 주입의 완료입니다. Pod Ready, LB target healthy, 실제 요청 성공과 작업 정합성을 확인해야 서비스 복구를 판정할 수 있습니다.

</details>

## 5. Spot 비용 절감의 올바른 비교 방식은?

- A) Spot 할인율을 그대로 서비스 절감률로 기록
- B) 같은 조건에서 정합성을 통과한 고유 성공 작업당 실효 비용 비교
- C) 재시도 비용과 On-Demand 대체 비용을 제외
- D) 중복 노드 비용을 EC2 청구서와 추가 비용에 두 번 합산

<details>
<summary>정답 보기</summary>

**정답: B) 같은 조건에서 정합성을 통과한 고유 성공 작업당 실효 비용 비교**

**설명:** 부대 비용과 약정 할인, 교체·재시도 영향을 반영하되 실제 사용 비용에 이미 포함된 금액은 중복 합산하지 않습니다. 단기 월 환산은 추정으로 표시합니다.

</details>

## 6. 실험 데이터가 없는 상태의 올바른 결과 기록은?

- A) 기대한 복구 시간을 실측 결과에 입력
- B) 오류율을 0으로 넣고 통과
- C) 미실행·측정값 없음으로 기록하고 운영 확대 보류
- D) 공식 문서가 있으므로 실험 완료로 처리

<details>
<summary>정답 보기</summary>

**정답: C) 미실행·측정값 없음으로 기록하고 운영 확대 보류**

**설명:** 문서 확인, 가설, 실측은 다른 증거입니다. 필수 실험의 실행 ID와 원시 결과가 없으면 운영 적용을 입증하지 못합니다.

</details>

## 7. E2 실측에서 혼합 경로의 전체 오류율은 0.0556%, 최악 60초 오류율은 0.8333%였습니다. 60초 오류율 기준이 0.1%라면?

- A) 전체 오류율이 낮으므로 통과한다
- B) p99가 낮으므로 요청 실패를 무시한다
- C) 해당 60초 기준을 충족하지 못했고, 현재 구성 보완 후 재실험해야 한다
- D) Spot은 모든 운영 서비스에서 사용할 수 없다

<details>
<summary>정답 보기</summary>

**정답: C) 해당 60초 기준을 충족하지 못했고, 현재 구성 보완 후 재실험해야 한다**

**설명:** 긴 정상 구간은 전체 오류율을 낮출 수 있습니다. 판정 창과 실제 업무 SLO를 맞추고, 이번 단일 합성 실험을 다른 구성의 보편적 결과로 확대 해석하지 않습니다.

</details>
