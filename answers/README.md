## 답변 구성

- 문제 번호 및 질문 요약
- 정답
- 상세 설명
- 관련 학습 자료 링크

3. 답변을 확인하고 이해가 되지 않는 부분은 관련 학습 자료를 다시 참조하세요.
4. 실습 문제의 경우, 답변에 제공된 단계를 따라 직접 실습해 보세요.
