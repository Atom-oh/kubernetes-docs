# Kubernetes と EKS トレーニングコンテンツのクイズ

このディレクトリには、Kubernetes と Amazon EKS のトレーニングコンテンツ用クイズが含まれています。各クイズは、トピックの理解度を確認し、重要な概念を定着させるのに役立ちます。

## クイズの構成

各クイズは次のように構成されています:
- 多肢選択問題
- 短答問題
- ハンズオン問題（該当する場合）
- 発展問題（該当する場合）

すべてのクイズ問題にはトグル形式で回答が含まれているため、まず問題に取り組んでから回答を確認できます。

## クイズの使い方

1. まず、関連トピックの学習資料を読んでください。
2. クイズに取り組み、理解度を確認してください。
3. 各問題の下にある「回答を表示」トグルをクリックして、回答を確認してください。
4. 必要に応じて学習資料に戻り、概念を復習してください。
