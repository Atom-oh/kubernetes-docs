# クラウドと CNI の設計クイズ

1. DNS の応答はあるのに TCP 接続が失敗します。次に何をすべきですか？

   - A) DNS だけを根拠にバックエンドが正常と宣言する
   - B) 実際のターゲット、ポート、経路、制御、リスナーを調査する
   - C) すべてのセキュリティグループを開放する
   - D) リソースが存在しないと結論付ける

<details>
<summary>回答を表示</summary>

**回答: B**

**解説:** DNS が示すのは名前解決の証拠です。TCP と HTTP については、経路、ポリシー、アプリケーションの証拠をそれぞれ調べる必要があります。

</details>

2. AWS Load Balancer Controller とは何ですか？

   - A) すべての HTTP リクエストが通過するデータプレーン
   - B) すべての Pod のデフォルトゲートウェイ
   - C) AWS API を使ってロードバランサーリソースを管理するコントロールプレーンの調整機能
   - D) DNS キャッシュそのもの

<details>
<summary>回答を表示</summary>

**回答: C**

**解説:** リクエストが通るのはロードバランサーと実際のターゲットです。コントローラーの状態はデータプレーン通信とは別に調査してください。

</details>

3. EndpointSlice は ready ですが、ロードバランサーのターゲットは異常と判定されています。どう解釈すべきですか？

   - A) 登録、ポート、ヘルスチェック条件、経路を関連付けて調べる。状態が異なることがある
   - B) 両者は同じ意味なので、この観測はあり得ない
   - C) DNS TTL を変更すれば必ず直る
   - D) EndpointSlice を削除する

<details>
<summary>回答を表示</summary>

**回答: A**

**解説:** Readiness とロードバランサーのヘルスチェックでは、観測する主体と条件が異なります。各エンドポイントアドレスを、その条件および実際のターゲットと照合してください。

</details>

4. NetworkPolicy オブジェクトが存在する場合、ほかに何が必要ですか？

   - A) 何も必要ない。存在すれば適用されている証拠になる
   - B) すべての Pod を hostNetwork に移す
   - C) すべての AWS アカウントで管理者権限を得る
   - D) 対象 Pod、方向、対応 API、エンジンの有効化、実際のフローの証拠

<details>
<summary>回答を表示</summary>

**回答: D**

**解説:** オブジェクトの一覧だけでは、対象選択や適用は保証されません。ほかのマネージドポリシーや CRD が適用される場合もあります。

</details>

5. TGW に関する正しい区別はどれですか？

   - A) どちらも同じファイアウォールルールである
   - B) アソシエーションはアタッチメントが参照するルートテーブルを選び、プロパゲーションは経路を学習するテーブルを示す
   - C) プロパゲーションにより、アタッチメントは常にそのテーブルを使用する
   - D) 1 つのアタッチメントをすべてのテーブルに関連付ける

<details>
<summary>回答を表示</summary>

**回答: B**

**解説:** アタッチメントは 1 つのテーブルに関連付けられ、複数のテーブルへ経路をプロパゲートできます。参照経路と戻り経路を別々に確認してください。

</details>

6. クエリが AccessDenied を返し、エンドポイントを取得できませんでした。結果はどうなりますか？

   - A) トラフィック拒否の検証に成功した
   - B) 管理者ポリシーを自動的にアタッチする
   - C) 証拠を取得できない。承認された最小限のアクセス権限を得るか、提供された証拠を入手する
   - D) バックエンドが存在しない

<details>
<summary>回答を表示</summary>

**回答: C**

**解説:** 権限エラーはリソースやネットワークの状態を示すものではありません。不明を許可、拒否、または不存在に置き換えないでください。

</details>

7. パケット経路では、Service ClusterIP をどのように表現すべきですか？

   - A) 論理的な選択と実際のプロキシおよびターゲットへの転送を区別する
   - B) 常にノードの後ろにある物理ホップとして扱う
   - C) IP ターゲットへのリクエストすべてで必須とする
   - D) 戻り経路を省略する

<details>
<summary>回答を表示</summary>

**回答: A**

**解説:** 転送方法は、ターゲットの種類、プロキシの実装、ポリシーによって異なります。オブジェクト間の関係を必須のネットワーク上のホップとみなすと、診断を誤ります。

</details>

8. アカウントなしでハイブリッドルーティング設計だけをレビューしました。どの完了ラベルが適切ですか？

   - A) ライブフェイルオーバーを検証済み
   - B) パフォーマンスを保証
   - C) すべてのポリシーが適用済み
   - D) 設計レビュー完了。実環境の観測は未検証

<details>
<summary>回答を表示</summary>

**回答: D**

**解説:** 設計、提供された証拠の分析、実際の実験は、それぞれ証拠のレベルが異なります。結論は実施した内容の範囲に限定してください。

</details>
