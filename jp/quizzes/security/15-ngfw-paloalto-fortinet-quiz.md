# Palo Alto と Fortinet NGFW のクイズ

> **最終更新日**: 2026年10月15日

[章と一次資料を読む](../../security/15-ngfw-paloalto-fortinet.md)

### 1. 一般的な GENEVE サポートがあれば、AWS GWLB との互換性も確認できたことになりますか？

- A) はい。UDP 6081 で十分です
- B) いいえ。サポートされるベンダー統合と必要な AWS メタデータを確認してください
- C) はい。任意の管理 IP をピアにできます
- D) 製品ロゴだけが重要です

<details>
<summary>回答を表示</summary>

**回答: B) いいえ。サポートされるベンダー統合と必要な AWS メタデータを確認してください**

**解説:** リリース、インターフェイス、ポリシー、メタデータ処理を公式のデプロイモードに合わせてください。

</details>

### 2. アプライアンスのヘルスチェックが成功した場合、何が確認されますか？

- A) すべての IPS シグネチャが有効である
- B) すべてのクライアントで TLS 復号が機能する
- C) 構成済みのヘルスエンドポイントが応答したこと。検査全体が正常とは限らない
- D) N-1 のビジネス容量が十分である

<details>
<summary>回答を表示</summary>

**回答: C) 構成済みのヘルスエンドポイントが応答したこと。検査全体が正常とは限らない**

**解説:** ヘルスチェックに加えて、検査用カナリア、ポリシー/ライセンスの確認、アプリケーション測定を利用してください。

</details>

### 3. ベンダーのヘルスチェック例はどのように使用すべきですか？

- A) HTTP 80 はどこでも共通である
- B) どの応答ポートも相互に置き換えられる
- C) GENEVE データとヘルスチェックでは同じプロトコルを使用する必要がある
- D) 実際のテンプレート、ターゲットグループ、アプライアンスの応答に合わせる

<details>
<summary>回答を表示</summary>

**回答: D) 実際のテンプレート、ターゲットグループ、アプライアンスの応答に合わせる**

**解説:** マニュアルのガイドには、HTTP の禁止/プロファイルに関して矛盾する記述があります。曖昧さをそのまま自動化せず、選択したバージョン/テンプレートで TCP/HTTPS がサポートされるか、および実際の応答を確認してください。

</details>

### 4. 暗号化されたペイロードを検査するには何が必要ですか？

- A) サポートされている復号/終端機能と、テスト済みの信頼/互換性ポリシー
- B) GWLB のデプロイだけ
- C) GENEVE VNI だけ
- D) 正常なターゲットだけ

<details>
<summary>回答を表示</summary>

**回答: A) サポートされている復号/終端機能と、テスト済みの信頼/互換性ポリシー**

**解説:** GENEVE は暗号化でも TLS 終端でもありません。mTLS、証明書ピンニング、CA 信頼、プロトコルのサポート、適用除外を検証してください。

</details>

### 5. ALB の HTTPS ターゲットグループはバックエンド証明書を検証しますか？

- A) 常に検証する
- B) いいえ。AWS のドキュメントでは ALB はターゲット証明書を検証しないとされています
- C) GWLB が有効な場合に限り検証する
- D) WAF アクションが Block の場合に限り検証する

<details>
<summary>回答を表示</summary>

**回答: B) いいえ。AWS のドキュメントでは ALB はターゲット証明書を検証しないとされています**

**解説:** 転送時の暗号化と、必要なバックエンド ID 検証は、設計上別々の要件です。

</details>

### 6. ノードの SNAT 後にアプライアンスが確認できるアドレスはどれですか？

- A) 変更されないワークロード ID
- B) 常に元の Pod アドレス
- C) ノードアドレス。Pod を特定するには CNI/IPAM との関連付けが必要
- D) 常にユーザーのブラウザーアドレス

<details>
<summary>回答を表示</summary>

**回答: C) ノードアドレス。Pod を特定するには CNI/IPAM との関連付けが必要**

**解説:** 変換ポイントとタイムスタンプを記録してください。Pod アドレスが保持されても、それは永続的な ID ではありません。

</details>

### 7. GWLB ターゲットを個別に追加すると、ファイアウォールのセッション状態も複製されますか？

- A) 常に複製される
- B) GENEVE が UDP を使う場合に限り複製される
- C) ターゲットが同じ AZ を共有する場合に限り複製される
- D) いいえ。状態共有にはサポート対象のベンダー設計とテストが必要です

<details>
<summary>回答を表示</summary>

**回答: D) いいえ。状態共有にはサポート対象のベンダー設計とテストが必要です**

**解説:** フローの再割り当てと状態の複製は別のものです。障害、スケーリング、アップグレード中に既存/新規セッションをテストしてください。

</details>

### 8. アプライアンス設計を公正に比較できるベンチマークはどれですか？

- A) 実際のセキュリティ/復号プロファイルを適用したビジネストラフィックを測定し、N-1 容量、レイテンシ、エラーを評価する
- B) データシートの最大スループットだけ
- C) EC2 インスタンスの料金だけ
- D) 成功したヘルスチェックだけ

<details>
<summary>回答を表示</summary>

**回答: A) 実際のセキュリティ/復号プロファイルを適用したビジネストラフィックを測定し、N-1 容量、レイテンシ、エラーを評価する**

**解説:** トラフィックの構成、ライセンス、機能、AZ 経路、セッション条件を揃えてください。このドキュメント更新では、パフォーマンス結果を測定していません。

</details>
