# Kubernetes and EKS Training Content Quizzes

This directory contains quizzes for Kubernetes and Amazon EKS training content. Each quiz helps test your understanding of the topic and reinforces key concepts.

## Quiz Structure

Each quiz is structured as follows:
- Multiple Choice Questions
- Short Answer Questions
- Hands-on Questions (where applicable)
- Advanced Questions (where applicable)

All quiz questions include answers in toggle format, so you can attempt the questions first and then check the answers.

## How to Use Quizzes

1. First read the learning materials for the relevant topic.
2. Take the quiz to test your understanding.
3. Click the "Show Answer" toggle below each question to check the answer.
4. If needed, return to the learning materials to review concepts.
